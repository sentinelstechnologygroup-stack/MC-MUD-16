# Project instructions

This is the independent Montgomery County MUD 16 website. Read README.md before changes. Preserve district facts and original documents. Do not mark rates, appointments or policy drafts adopted without supporting district records.

Use npm scripts for local development, build, lint and tests. Public content is in src/data/public-content.json. The staff backend is unfinished; never enable client-only admin roles or simulate successful writes. Keep private exports and credentials out of the public bundle and Git.

Deploy with the linked Vercel mcmud16 project and the MC-MUD-16 GitHub repository. Do not change the district's custom domain without explicit cutover authorization.
